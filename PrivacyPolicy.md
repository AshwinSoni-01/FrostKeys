# Privacy Policy for Mango.brrrBoard

Mango.brrrBoard is an offline-first personal Android keyboard. This build does not request network access, does not include cloud AI or online media search, and does not request Contacts permission.

Voice recognition is invoked only when the microphone key is used and is delegated to Android's selected speech-recognition service.

Crash reports remain local. They are not uploaded automatically; a user can explicitly export a crash-report file and share it for debugging.
